# IPA Desktop

Графический интерфейс для поиска, скачивания и установки IPA на Windows 10/11 x64. Написан на C# и WPF.

**Тестовая версия: 0.1.7.** Независимый проект: оболочка использует утилиты и каталог из [IPA Downloader](https://github.com/kda2495/IPA_Downloader), но не является официальным интерфейсом его автора.

## Скачать и запустить

[Скачать IPA Desktop 0.1.7 для Windows](https://github.com/Lis1us/IPA-Desktop/releases/download/v0.1.7/IPA-Desktop-0.1.7-Windows.zip)

1. Полностью распакуйте ZIP в отдельную папку.
2. Запустите `IPA-Desktop.exe`. Оставьте `MainWindow.xaml` и `IPA-Desktop.exe.config` рядом.
3. При первом запуске дождитесь скачивания движка из GitHub Releases.
4. Нажмите «Войти в Apple Account». Почта, пароль и 2FA вводятся в штатном консольном окне ipatool.
5. Найдите приложение по названию или числовому App Store ID, выберите версию и скачайте IPA.

Нужны .NET Framework 4.6 или новее и доступ к GitHub/App Store. Для установки на iPhone требуется Apple Mobile Device Support. Подключите устройство по USB, разблокируйте его и подтвердите доверие компьютеру. Запуск GUI от администратора не требуется.

## Возможности

- Поиск по каталогу IPA Downloader, пользовательскому списку и App Store; объединение без дублей.
- Последняя или конкретная версия приложения, сведения о номере и дате выпуска.
- Последовательное скачивание нескольких приложений, журнал и отмена операции.
- Просмотр локальных IPA, импорт и удаление выбранных файлов в корзину.
- Обнаружение USB-устройств и установка IPA через ideviceinstaller.
- Проверка сохранённого аккаунта; кнопка входа неактивна после подтверждения сессии.
- Обновление движка из релизов IPA Downloader и откат к предыдущей версии.

## Обновления и данные

Автообновление движка включено по умолчанию и выполняется при запуске. Архив проверяется по размеру и SHA-256 из GitHub API, если она предоставлена. Перед переключением проверяются запуск и основные команды утилиты. Откат отключает автообновление, чтобы не вернуть проблемную версию.

GUI непосредственно запускает утилиты из архива IPA Downloader. Новая логика его PowerShell-скрипта не переносится автоматически. Начиная с 0.1.6 программа проверяет новые версии IPA Desktop при запуске. Во вкладке «Обновления» можно проверить версию вручную и установить обновление после подтверждения. ZIP скачивается только из Releases этого репозитория, проверяется по размеру и SHA-256. Программа перезапускается, файлы предыдущей версии временно сохраняются для восстановления; при ошибке копирования выполняется откат. Для установки нужна доступная для записи папка (например, в профиле пользователя). Версии 0.1.5 и старше нужно обновить вручную один раз.

| Данные | Расположение |
|---|---|
| Скачанные IPA | `%LOCALAPPDATA%\IPA-Desktop\Apps` |
| Версии движка | `%LOCALAPPDATA%\IPA-Desktop\Versions` |
| Настройки GUI | `%LOCALAPPDATA%\IPA-Desktop\state.json` |
| Пользовательский каталог | `%LOCALAPPDATA%\IPA-Desktop\Files\AppsListCustom.txt` |
| Штатная сессия ipatool | `%USERPROFILE%\.ipatool` |

Пользовательский каталог: по одной записи `Название: ID` на строку. Сессия ipatool используется совместно с оригинальным скриптом. GUI не получает пароль из консольного окна входа и не передаёт его аргументом процесса; хранением сессии занимается ipatool.

Удаление IPA не удаляет приложение с iPhone. Для окончательного освобождения места очистите корзину Windows.

## Сборка из исходников

Запустите `Build.cmd` в Windows. Используется штатный компилятор .NET Framework; Visual Studio и NuGet не требуются. `Start.cmd` запускает EXE либо предварительно собирает его, если он отсутствует.

`Verify.ps1` проверяет настройки, JSON, откат и загрузку XAML без обращения к Apple. Запускайте его в Windows PowerShell 5.1 в режиме STA.

## Ограничения тестовой версии

- Вход и 2FA проходят в отдельном консольном окне. Выбор нескольких аккаунтов и дополнительная keychain-passphrase в GUI не поддерживаются.
- В списке версий отображаются внешние ID Apple; человекочитаемый номер доступен в «Сведениях».
- Проверка сохранённой сессии не гарантирует, что Apple не запросит повторный вход при скачивании.
- Предварительная проверка минимальной iOS не реализована: результат установки сообщает ideviceinstaller.
- Загрузка использует `--purchase` для получения бесплатной лицензии при необходимости. Права аккаунта и доступность приложения у Apple сохраняют силу.
- Старые папки движка автоматически не удаляются. Отмена установки не откатывает уже установленное приложение.
- Базовые проверки кода и компонентов проведены; полноценная проверка всех сценариев Windows/Apple/iPhone пока не завершена. Сообщения об ошибках можно публиковать в Issues, предварительно убрав персональные данные.

## Изменения 0.1.6

Во вкладке «Файлы и устройство» добавлена колонка **Apple Account**. Значение читается из поля `appleId` / `AppleID` внутри `iTunesMetadata.plist` каждого IPA (XML и бинарный plist). Работает также для импортированных файлов; текущий вход в программе не подставляется вместо владельца файла.

Если данных нет, показано «Не указан»; при повреждении файла — «Не удалось прочитать». Метаданные не являются проверкой прав установки со стороны Apple. Имя владельца из `userName` не считается адресом аккаунта. Чтение списка выполняется в фоне. Адреса остаются в локальном интерфейсе, не отправляются на GitHub и не сохраняются в исходниках.

## Публикация сборок

Готовые ZIP размещаются в [GitHub Releases](https://github.com/Lis1us/IPA-Desktop/releases). При изменении номера версии в `MainWindow.xaml` в ветке `main` GitHub Actions собирает приложение на Windows, запускает проверки и публикует новый релиз. Уже опубликованные версии не перезаписываются. Workflow также можно запустить вручную через Actions / Windows release / Run workflow.

## Оформление 0.1.6

Новая иконка смартфона со стрелкой загрузки, тёмные списки версий, более чёткое выделение строк и состояния кнопок. Системная панель заголовка использует тёмную тему Windows 10/11; Windows 11 также поддерживает точный цвет фона приложения. На старых сборках Windows, не поддерживающих тёмный заголовок, сохраняется стандартная рамка. Системные кнопки, изменение размеров и привязка окон остаются штатными.
