# IPA Desktop Device Tools 1.0.1

- Переработана упаковка зависимостей: MinGW и System32 индексируются один раз, очередь DLL не выполняет повторные обходы каталогов.
- Добавлены проверки зависимостей, циклов, регистра имён и запрет зависимости от MSYS runtime.
- Контрольные суммы файлов считаются потоково без чтения целой DLL в память.
- Параллелизм сборки выбирается по доступным CPU с ограничением до 8 заданий.
- Исходные ревизии libimobiledevice и ideviceinstaller сохранены. Этот выпуск улучшает сборку и проверку комплекта; увеличение скорости передачи IPA не заявляется.

Сетевые флаги всех трёх утилит и запуск вне MSYS2 проверяются перед публикацией. Лицензии и исходники приложены.
