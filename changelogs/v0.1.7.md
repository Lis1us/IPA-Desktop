## Что нового

- Общий список выбранных приложений внизу вкладки **«Поиск и загрузка»**.
- Выбор сохраняется между поисками: можно собрать MAX, Telegram и другие приложения с разными названиями.
- **«В выбранное»** добавляет выделенные строки; Ctrl / Shift выделяют несколько результатов сразу.
- Для каждого приложения сохраняется своя выбранная версия.
- Повторное добавление того же App Store ID обновляет запись без дубликата.
- Крестик убирает одно приложение, **«Очистить»** — весь список.
- **«Скачать (N)»** загружает приложения по очереди с отображением текущего номера.
- Успешные загрузки убираются из списка; ошибочные и ещё не скачанные остаются для повтора.
- Скорректирована компоновка окна для панели выбранных приложений.

Выбор сохраняется в текущем сеансе и сбрасывается при закрытии программы.

## Как обновиться

Из версии 0.1.6: **«Обновления» → «Проверить версию» → «Обновить до v0.1.7»**.

Либо скачайте IPA-Desktop-0.1.7-Windows.zip, полностью распакуйте и запустите IPA-Desktop.exe. Скачанные IPA и настройки сохранятся. Windows 10/11 x64, .NET Framework 4.6 или новее.

## Проверки

На Windows-сервере GitHub прошли сборка, проверки выбора между поисками, отсутствия дублей, индивидуальных версий, интерфейса и механизма обновления/отката.
