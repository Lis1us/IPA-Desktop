# IPA Desktop 0.2.3

- Добавлена таблица версий: ID, номер, минимальная ОС и платформы. Метаданные выбранных строк загружаются по запросу, с прогрессом, отменой и ожиданием не более 30 секунд на версию.
- Можно вручную добавить известные ID версий и скачать несколько версий одного приложения. Удаление из очереди и повтор ошибок различают версии; наборы остаются независимыми от версий и Apple Account.
- Перед установкой проверяются платформа IPA и минимальная iOS по Info.plist отправляемого файла; поддерживаются XML и binary plist. Отсутствие данных не считается подтверждением совместимости.
- Добавлена экспериментальная установка по Wi-Fi: совместный поиск USB и сети, явная подпись подключения, подсказки настройки и проверка связи перед каждой установкой.
- Сбой одного способа обнаружения не удаляет результаты другого. При обрыве установки нет скрытого перехода на USB и автоматического повтора; ошибки можно повторить вручную после проверки телефона.
- Расширены проверки очередей, ручных ID, метаданных, совместимости и сетевого транспорта. Поддержка сетевых флагов проверяется на настоящем Windows-комплекте инструментов.

Для Wi-Fi предварительно настройте доверие по USB и сетевую синхронизацию в Apple Devices/iTunes. На физическом iPhone новый режим ещё не проверен.
