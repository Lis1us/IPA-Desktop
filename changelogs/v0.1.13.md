## Структура проекта и файлов программы

- Иконки перенесены в Assets, проверки — в Tests, служебные скрипты — в Scripts, документация — в Docs.
- Автоматические файлы компиляции находятся в Generated; классы для разработки остаются в Source.
- Обновлены пути загрузки иконки, сборки, тестов, упаковки и GitHub Actions.
- Добавлен совместимый переход из версий с файлами в корне: новая программа при первом запуске раскладывает встроенные файлы по папкам и убирает совпадающие служебные копии.
- Изменённые пользователем файлы не удаляются.
- Добавлены проверки старого updater, новой структуры, повторного запуска, сохранения файлов и сборки перенесённой папки.

ZIP содержит совместимые копии для прежнего механизма обновления; после первого запуска они убираются из корня. Скачанные IPA и настройки сохраняются в прежнем месте.

## Обновление

«Обновления» → «Проверить версию» → «Обновить до v0.1.13», либо полностью распакуйте IPA-Desktop-0.1.13-Windows.zip. Windows 10/11 x64, .NET Framework 4.6 или новее.
