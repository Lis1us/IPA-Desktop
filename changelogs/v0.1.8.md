## Что нового

- Клик **ЛКМ по строке приложения** сразу добавляет его в выбранное для скачивания.
- Повторный клик не создаёт дубль и не сбрасывает ранее выбранную версию. Кнопка «В выбранное» позволяет обновить версию или добавить выделенную группу.
- Во вкладке **«Файлы и устройство»** появился отдельный список выбранных IPA снизу.
- ЛКМ добавляет файл к установке. Крестик убирает его из списка, не удаляя IPA с диска; «Очистить» сбрасывает весь список.
- После выбора iPhone кнопка **«Установить (N)»** устанавливает весь список по очереди после подтверждения.
- Успешные установки убираются из списка, ошибочные и незавершённые остаются для повтора.
- Обновление файлов сохраняет выбор существующих IPA; удалённые файлы исключаются из списка установки.

Скачивание и установка запускаются только соответствующими кнопками. Оба списка сбрасываются при закрытии программы.

## Как обновиться

В версии 0.1.6 или новее: **«Обновления» → «Проверить версию» → «Обновить до v0.1.8»**.

Либо полностью распакуйте IPA-Desktop-0.1.8-Windows.zip и запустите IPA-Desktop.exe. Windows 10/11 x64, .NET Framework 4.6 или новее. Для установки IPA нужен Apple Mobile Device Support и доверие iPhone к компьютеру.
