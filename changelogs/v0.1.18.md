## Наборы по App Store ID

- Наборы сохраняют ID и названия приложений без привязки к Apple Account, iPhone или скачанным IPA.
- Сохраняйте выбранные приложения из поиска либо извлекайте ID из выбранных IPA.
- Добавление набора открывает очередь скачивания: последние доступные версии загружаются заново под текущим аккаунтом, затем их можно установить на нужный iPhone.
- Каждое скачивание получает отдельное имя файла: загрузки разных аккаунтов не перезаписываются.
- Прежние наборы преобразуются по метаданным исходных IPA. Если файла или ID нет, показывается понятное сообщение без подстановки чужого IPA.
- Добавлены проверки формата ID, преобразования прежних наборов, независимости от файлов и повторных загрузок.
