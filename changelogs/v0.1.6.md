## Что нового

- Тёмная системная рамка окна для поддерживаемых сборок Windows 10/11. На Windows 11 её фон совпадает с цветом приложения.
- Новая иконка — смартфон со стрелкой загрузки.
- Обновлены кнопки, вкладки, выделение строк и выпадающий список версий.
- Добавлен отдельный блок обновления **самого IPA Desktop** из Releases этого репозитория.
- При запуске программа проверяет новые версии. Проверку можно отключить или запустить вручную.
- Установка обновления начинается после подтверждения: проверяются размер и SHA-256 ZIP, сохраняется резервная копия файлов, программа перезапускается. При ошибке копирования выполняется откат.
- Скачанные IPA, движок и настройки не заменяются обновлением GUI.

## Как обновиться

С версии 0.1.5 и старше: один раз скачайте IPA-Desktop-0.1.6-Windows.zip, полностью распакуйте в доступную для записи папку и запустите IPA-Desktop.exe.

Следующие версии устанавливаются через вкладку **«Обновления»**. Windows 10/11 x64, .NET Framework 4.6 или новее.
