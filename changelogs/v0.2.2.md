# IPA Desktop 0.2.2

- В «Сведения о версии» добавлены минимальная версия ОС из ipatool 1.1.9+ и поддерживаемые платформы из ipatool 1.2.0+.
- Сохранена совместимость со старыми версиями движка и ответами без новых необязательных полей: отсутствующие данные отмечаются явно.
- iOS и macOS различаются в сведениях; отсутствие платформ не считается подтверждением совместимости с iPhone.
- Добавлены проверки Windows-архивов ipatool 1.1.9 и 1.2.0: загрузка с SHA-256, запуск CLI, установка и откат без изменения инструментов iPhone.

Движок обновляется отдельно: «Настройки» → ipatool → «Проверить обновления».
