## Изменения

- ipatool теперь скачивается и обновляется напрямую из Releases Sorvigolova/ipatool для Windows x64.
- Из IPA Downloader используются каталог приложений и инструменты установки на iPhone с DLL; скрипты и его копия ipatool больше не нужны.
- Существующие инструменты для iPhone сохраняются при переходе. На чистой установке импортируется только нужный комплект.
- Версии и источники движка учитываются раздельно: одинаковые номера релизов не препятствуют миграции, откат сохраняет инструменты установки.
- Каталог может загружаться без установленного движка; при недоступности сети используется сохранённая копия.
- Скачанные IPA и настройки сохраняются.
