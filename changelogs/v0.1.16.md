## Изменения

- Инструменты для iPhone теперь получаются из наших отдельных Releases — сборок libimobiledevice и ideviceinstaller из исходников.
- От IPA_Downloader остался только каталог приложений. Его архивы и скрипты больше не скачиваются.
- Добавлена миграция на наш комплект с сохранением прежних инструментов для отката.
- Комплект включает необходимые DLL, лицензии и сведения об исходных ревизиях; рядом с ним опубликованы исходники.
- Обновления и откат комплекта остаются независимыми от ipatool и интерфейса.
- Для подключения iPhone по USB по-прежнему требуется служба Apple Mobile Device.
